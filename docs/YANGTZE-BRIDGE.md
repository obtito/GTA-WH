# 武汉长江大桥模型细化

2026-10-08。主站仍使用程序化模型；本轮没有导入额外贴图或外部模型。

## 结构与外观

- 主跨按九孔、八个江中实体墩组织，两片主桁位于公路下方。主弦杆、斜杆、副竖杆、横向联结和节点板分层表达。
- 上层四车道、双黄线及两側人行道；下层双线铁路、轨枕、检修护栏。列车改为一台牵引车头加七节客车：斜面驾驶室风挡、前灯、进气格栅、弧形车顶、双色窗带、带把手的车门与登车踏步、折叠连接风挡、圆形轮对和转向架。保留绿皮客运列车的低饱和配色，并保持 24 米连续车距。这是通用客运列车造型，未标称特定机车型号。
- 两岸各一组双塔桥头堡：灰石收分塔身、长拱花窗、阳台、露台栏杆、浅灰双层亭檐与小型暗红顶珠。桥头堡底座接到场景地形，全部构件留在人行道外侧。
- 引桥补充混凝土拱肋与支撑。修正原桥面实体反向的三角面绕序，避免从上方看到底板及透出的支撑杂面。
- 地标列表选择桥梁时按整座桥长取景，可用滚轮继续放大观察。
- 下层铁路从两端主跨继续接入岸上线路：使用同一实体带状桥面，圆滑转弯，两端竖向切线保持水平；汉阳、武昌接线分别约 1.25、1.91 公里，最大坡度分别约 2.62%、1.68%。按场景建筑碰撞盒和地形规划绕行，补齐钢轨、1.6 米间距轨枕、墩柱和落地段挡土填充。线路是为了适配现有场景的接线，不是京广铁路实测线位。
- 公路引桥使用五次缓和曲线；两端宽度在 60 米内从 8.5/15.4 米展开到主桥 22 米，护栏、人行道和标线跟随。岸上两条“桥头接线”改为顺着引桥的出桥方向再转弯，分别接入龟山北路、临江大道，避免原落点处的折返。地标卡增加“汉阳桥头”“武昌桥头”近景按钮。
- 近距整桥视角暴露了江面与其下方大地面的深度闪烁；对水面增加小幅多边形深度偏移，保持正常深度遮挡，原角度复查绿色条块消失。

桥轴仍沿用现有场景的约测坐标，与简化岸线、道路相衔接；桥面高程和局部尺寸按游戏地形与实景比例安排，不是工程测绘复原。主桥路面场景标高 36 米，下层铁路板比路面低 18.7 米。

## 重复路面修复

原始 OSM 两条车道与精建桥轴偏离，旧去重只检查桥面宽度，留下低位跨江路面。现在结合桥名、有限地理范围及完整道路单元是否跨水识别重复路面；保留岸上引道、无关近邻桥及远处同名桥。仍保留原精确桥面覆盖检查。

## 验证

```bash
node tools/train-check.mjs
node tools/bridge-check.mjs
node tools/bridge-connection-check.mjs
node tools/road-clearance.mjs
node tools/heights.mjs
node tools/city-loading-check.mjs
node --experimental-vm-modules tools/check.mjs
```

桥梁检查包含实体朝向、所有桥面的高度查询、八个主墩位置、四塔实际顶点的人行道净空、列车净高/车距，以及车辆双向完整过桥。道路检查验证原重复跨水三角面清零、四个原始岸端和全部十个桥头连接保留，同时检查无关桥梁未被误删。碰撞数据加载的九项回归保持通过。

新增接线检查覆盖实际铁路桥面顶点、两端位置/高度/切线、坡度、城市建筑和山坡净空、原引桥拱肋/桥头堡的列车空间，以及岸上公路接线未被净空裁剪、出桥方向一致、路面高度和宽度连续。

含约 3.16 公里新铁路接线后，长江大桥约 19.1 万三角形、46 个网格批次；主桥本体仍保持约 9.8 万三角形，铁路接线使用额外 7 个批次。这里是模型统计，不代表实际浏览器 FPS。浏览器核对了开场黑线消失、桥头近景路面、下层列车、昼夜显示和控制台。

重新规划接线时依次运行 `node tools/build-rail-approaches.mjs` 和 `node tools/build-bridge-ground-links.mjs`；若重建整体岸上路网，需在 `tools/build-road-network.mjs` 之后运行后者，保留两处圆滑桥头接线。两项规划仅读取既有城市和岸线数据。

## 火车近景与验证

`docs/train-review.html` 直接引用主站使用的 `js/yangtze-train.js`，可切换车头、客车及八节编组视角。整列车为 11 个材质批次、10,040 个三角形，动画继续使用动态实例矩阵，无每帧模型重建。细小窗框使用平面细节，轮对保留实体圆形几何。

`tools/train-check.mjs` 检查实际合并后的模型表面：64 个车轮在 1.435 米轨距上贴合轨面、车顶弧度、包围尺寸、前灯材质和三角形预算；覆盖完整进出桥跨循环，验证车头/车厢各材质同步与车距。缩小轮径的负对照会触发浮轮失败。主桥检查继续验证列车桥内净空、主桥预算与车辆双向过桥。近景截图见 `docs/screenshots/train-head-20261008.jpg`、`train-coach-20261008.jpg`、`train-consist-20261008.jpg`。
