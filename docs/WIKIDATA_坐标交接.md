# Wikidata 实测坐标交接（P625）

共 **36** 个武汉实体，全部来自 Wikidata 的 `coordinate location (P625)`，每条都带 QID 可回溯。机器可读版本：`data/wikidata-coords.json`。

> 由 `python scripts/export_coords.py && python scripts/make_handoff_doc.py` 生成，请勿手改。

## 用法建议

```js
import coords from './data/wikidata-coords.json';
const byId = Object.fromEntries(coords.landmarks.map(l => [l.qid, l]));
```

- 坐标系：**WGS84**，与 GMaps/AMap 抓取的 GCJ-02 不同，**不要直接混用**。
- 如果现有 `js/data.js` 的坐标来自 GCJ-02 源，请用同一套基准批量换算后再比较。把两套行李混合会让地标相对路网漂移几百米。
- Wikidata 事实为 CC0，商业再分发需在 `data/ATTRIBUTION.md` 留一句声明。

**读法**：偏差方向不一致（有的偏东有的偏西），所以这不是坐标系基准差，而是取点精度问题——多数点位落在 0.2–1.4 km，`武汉绿地中心` 一条达到 3.7 km。建议把差值最大的几条（尤其是用来锚定**长江/汉江中心线**的那几条）换成 Wikidata 值。
